# Gestor SGC REVITAM

Gestor web demostrativo del Sistema de Gestión de Calidad REVITAM.

## Publicación en GitHub Pages

1. Subir todos los archivos y la carpeta `assets` al repositorio `gestor-sgc-revitam`.
2. Ir a **Settings → Pages**.
3. Elegir **Deploy from a branch**.
4. Seleccionar la rama `main` y la carpeta `/ (root)`.
5. Pulsar **Save**.

Los documentos oficiales permanecen en Google Drive. Este repositorio contiene la interfaz del gestor y sus enlaces.
